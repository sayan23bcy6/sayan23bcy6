# Featured Projects

## Datamind

An autonomous data quality, repair, and investigation platform. It pairs deterministic statistical detectors with an adversarial Investigator and Critic agent loop, and verifies every repair against Kolmogorov-Smirnov and Population Stability Index tolerances. Each dataset version keeps immutable lineage and cryptographic hashes. The system is served through a FastAPI gateway, Celery workers, and a React dashboard with live progress over Server-Sent Events.

**Tech Stack**

`Python` `FastAPI` `Celery` `PostgreSQL` `pgvector` `Redis` `React` `Docker`

**GitHub:** https://github.com/sayan23bcy6/Datamind

---

## Distributed Rate Limiter with Live Dashboard (Gatekeep)

A distributed rate limiter that multiple API instances share through Redis. It combines a token bucket for burst-tolerant per-second limits with a sliding window log for per-minute quotas. Redis Lua scripts keep each check atomic, and server-side time inside Redis avoids clock skew between instances. A React dashboard streams allowed and blocked request counts in real time. The service is containerized with Docker Compose and includes a k6 load test.

**Tech Stack**

`Python` `FastAPI` `Redis` `Lua` `SQLAlchemy` `React` `Recharts` `Docker` `k6`

**GitHub:** https://github.com/sayan23bcy6/Gatekeep

## The Research Assistant Crew

A multi-agent research system in which a manager agent plans a research question, specialist search, analysis, and writing agents execute it, and the manager reviews the final report. The workflow is built as a LangGraph state graph with bounded retry loops. Sources are handled as structured data and referenced by index, and every URL in the final report is validated against the retrieved set. The app ships with a Streamlit interface, Markdown export, Docker support, and CI with pytest and linting.

**Tech Stack**

`Python` `LangGraph` `LangChain` `Groq` `Tavily` `Pydantic` `Streamlit` `Docker`

**GitHub:** https://github.com/sayan23bcy6/Multiagent_research_assistant_crew
